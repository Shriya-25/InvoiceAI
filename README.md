# InvoiceAI

AI-Powered invoicing web application that lets freelancers and small businesses generate, manage, and export professional invoices using natural language prompts or a manual builder.

## Tech Stack
- **Frontend**: React + Vite + Tailwind CSS v3 + React Router + Recharts
- **Backend**: Node.js + Express (Proxy API layer)
- **Database/Auth**: Firebase Firestore & Firebase Auth
- **AI Engine**: Google Gemini API
